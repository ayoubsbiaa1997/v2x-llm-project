# NGSIM US-101 Raw Dataset

The original NGSIM US-101 files are third-party data and are not distributed
with this repository.

Expected raw trajectory file:

trajectories-0750am-0805am.txt

Place the downloaded NGSIM US-101 source files in this directory before
running the preprocessing and external-validation pipeline.

The repository contains the preprocessing, mapping, ML inference and LLM
validation scripts required to reproduce the experiments once the original
NGSIM data have been obtained from the official source.
