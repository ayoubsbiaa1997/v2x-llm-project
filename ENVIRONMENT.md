# Experimental Environment

The Python components of this project were validated with:

- Python: 3.12.3
- NumPy: 2.5.1
- Pandas: 3.0.5
- Matplotlib: 3.11.1
- Seaborn: 0.13.2
- Scikit-learn: 1.9.0
- XGBoost: 3.4.0
- Joblib: 1.5.3
- SHAP: 0.52.0
- PyTorch: 2.13.0
- Local PyTorch CUDA build tested: 2.13.0+cu130

The networking and mobility components rely on ns-3 / 5G-LENA and SUMO.
External mobility validation uses the NGSIM US-101 dataset, which must be
downloaded separately and is not redistributed in this repository.
